ENGLISH
--------------------------------------------------------------------------------

PC Doctor is a maintenance tool that can change Windows system settings and
runs with administrator privileges. Installing and using it means you accept
the terms below.

- Operations requiring admin rights (System Restore point, sfc/DISM repair,
  chkdsk /f, enabling firewall/UAC, pagefile configuration) ask for your
  explicit confirmation every time; none of them run without your consent.

- chkdsk /f repairs the file system; on the system drive it requires a
  reboot. A System Restore point is created before every chkdsk /f.

- The large/unused-file finder moves the files you select to the Recycle
  Bin (not a permanent delete) - you can restore mistaken selections from
  there.

- System setting changes (UAC, firewall, pagefile) only ever strengthen
  security.

- The software is provided "AS IS", without warranty of any kind. Backing
  up important data before critical operations is recommended.

- For serious hardware failure or data-recovery scenarios, consult a
  professional technician.
