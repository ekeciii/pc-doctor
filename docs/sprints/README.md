# Sprint design docs

This folder holds the per-sprint design documents from PC Doctor's build
phase (Sprint 2 through Sprint 12). Each follows the same pattern: a
4-lens scope workflow → a written spec → 3-4 implementation phases.

**This practice stopped after Sprint 12.** Sprints 13 onward (and all
work since) are tracked in [`CHANGELOG.md`](../../CHANGELOG.md) and git
history instead — a per-sprint design doc made sense during the initial
build-out but became unnecessary overhead once the app reached feature
completeness. There was no retroactive write-up for Sprints 13-15; the
user's session memory and `CHANGELOG.md` are the record for that period
going forward.

If you're looking for the current architecture and non-negotiable rules,
see [`CLAUDE.md`](../../CLAUDE.md) instead — these sprint docs are a
historical record, not necessarily accurate to the current codebase.
